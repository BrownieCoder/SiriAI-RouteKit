# 客户端导入能力与证据

核验日期：2026-09-22。范围仅安装方式；既有域名、候选审计与 Apple 资格结论不变。客户端 GUI 导入、浏览器协议提示后的下载、真实规则命中和 Siri 功能都尚未实测。

## 当前项目地址状态

匿名 GitHub API 返回公开仓库 `BrownieCoder/SiriAI-RouteKit`，默认分支 `main`、`has_pages=false`。现有 `examples/clash-meta.yaml` raw 为 200；新模块、远程示例和 Pages 安装页均为 404。不能将新地址写成当前可用的一键入口。

README 当前提供文件安装入口；`install/` 的纯静态页面已准备，须授权发布并核对后才将入口改成 HTTPS 安装页。普通 GitHub HTML 文件浏览页不能代替托管页面。本次未修改 Pages setting 或权限。[发布步骤](维护与来源.md#安装资产与发布边界)。

## Shadowrocket：官方、社区与未实测项

[App Store](https://apps.apple.com/us/app/shadowrocket/id932747118)确认支持 URL 导入规则，并链接到开发者官网 [shadowlaunch.com](https://shadowlaunch.com/)。本次没有找到开发者公开的 module scheme、策略与排序协议，不能把同名第三方站当官方。

[LOWERTOP 社区原始手册](https://github.com/LOWERTOP/Shadowrocket)记录以下行为（均保留社区归属）：

- [URL schemes](https://github.com/LOWERTOP/Shadowrocket#url-schemes)：`shadowrocket://install?module={url}`。
- [模块](https://github.com/LOWERTOP/Shadowrocket#模块)：模块的格式及远程添加方式；纯规则模块使用配置路由。
- [规则策略](https://github.com/LOWERTOP/Shadowrocket#规则策略)：内置 `PROXY` 使用现有代理选择，不要求本项目自建策略组。
- [规则优先级](https://github.com/LOWERTOP/Shadowrocket#规则优先级)：模块高于主配置，规则依序匹配。

公开的[社区 HTTPS raw 模块实例](https://raw.githubusercontent.com/GMOogway/shadowrocket-rules/master/sr_proxy_list.module)证明此分发形式存在实际用例，不证明本项目导入成功。

**优先级限制：** 本模块五域完全精确，但仍可能先于主配置对这些目标的 `REJECT`、`DIRECT` 或自定义策略。其他安全模块也可能更早命中。保留安全拦截需要用户检查冲突；不要求无条件把本模块移到全部规则最前，不重排私人配置。模块顺序、重复导入、自动启用、TCP/UDP 最终路由未作真机验证。

## 无节点示例为何需要醒目标识

`examples/clash-remote.yaml` 的空节点列表不提供可用出口。启用后五域选 `REJECT`，其余 `MATCH,DIRECT`。ClashX 自动切换会使原来代理的其他连接改成直连；这不是无影响的安装测试。CTA 之前必须说明这一点，日常使用指向配置副本教程。

两个示例已用 Mihomo v1.19.31 的隔离 HomeDir 做 `-t` 解析，结果见[验证记录](验证记录.md)；不等于 ClashX/Verge GUI 和真实转发通过。

## GitHub 为什么需要 HTTPS 安装页

[GitHub Markup](https://github.com/github/markup/blob/master/README.md)说明渲染会清洗 HTML。2026-09-22 用[官方 Markdown API](https://docs.github.com/en/rest/markdown/markdown)匿名执行只读渲染：`POST /markdown`，`markdown` 和 `gfm` 两种 mode 均 HTTP 200。

输入包括 HTTPS 对照、`shadowrocket://install?module=...`、`surge:///install-module?...` 的 Markdown，以及手写 Shadowrocket `<a>`。两模式保留 HTTPS 的 `<a href>`，其他三项均变成仅有文字的 `<p>`。没有创建 issue、comment 或公开内容。这证明本次渲染会移除 scheme 链接，不能只在 README 写 custom scheme。

[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)可托管纯静态页面。安装页只允许固定下载目标，哈希检查失败不唤起 App；自动尝试不代表安装成功，不借失焦或计时器推断成功。[WebKit Clipboard](https://webkit.org/blog/10855/async-clipboard-api/)要求安全上下文和用户手势，因此复制由点击直接触发，失败仍能选中完整 URL。
